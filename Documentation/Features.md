# HealthCare+ Features

HealthCare+ is a personal health monitoring web application for tracking daily health and wellness information.

## Health Monitoring

### BMI
Calculates BMI using the entered height and weight.

### Water Intake
Tracks the number of glasses of water consumed during the day.

### Steps
Tracks daily steps and shows progress towards the daily target.

### Sleep
Tracks the number of hours slept and shows progress towards the daily target.

### Calories
Tracks daily calorie intake.

## Wellness

### Wellness Score
Calculates an overall score based on the tracked daily health information.

### Nutrition Score
Provides a score based on the entered calorie information.

### Daily Goals
Displays progress towards daily water, steps, and sleep targets.

### Daily Challenges
Shows a simple daily health challenge based on the current progress.

### Streaks
Tracks completion of the daily health goals.

### Achievements
Displays achievements when selected daily goals are reached.

## Personal Tracking

### Mood Tracking
Allows the user to record their current mood.

### Menstrual Cycle Tracking
Allows the user to record a menstrual cycle date.

## Dashboard

The dashboard provides a centralized view of the user's health and wellness information and daily progress.
