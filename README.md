# HealthCare+ – Personal Health Monitoring System

A personal health monitoring web application for tracking daily health and wellness information.

## Features

- BMI calculation
- Water intake tracking
- Steps tracking
- Sleep tracking
- Calorie and food intake tracking
- Wellness score
- Daily goals
- Nutrition score
- Daily challenges
- Consecutive-day streaks
- Achievements
- Mood tracking
- Menstrual cycle tracking

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Overview

The application provides a centralized dashboard to monitor personal health information and daily progress.

Interactive modules are used to calculate health metrics, track daily targets, and display progress through the dashboard.
